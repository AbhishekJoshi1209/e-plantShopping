# 🌿 E-Plant Shopping

An interactive **e-commerce web application** for browsing and purchasing plants online.
Built using modern frontend technologies, this project demonstrates core concepts of **React, Redux, and state management**.

---

## 🚀 Features

* 🛍️ Browse a variety of plants
* 🧺 Add to cart functionality
* ➕ Increase / ➖ decrease quantity
* 💰 Dynamic total price calculation
* 🌱 Categorized plant collections (e.g., Air Purifying, Aromatic, etc.)
* 📱 Responsive design for all devices

---

## 🛠️ Tech Stack

* **Frontend:** React
* **State Management:** Redux Toolkit
* **Build Tool:** Vite
* **Styling:** CSS
* **Deployment:** GitHub Pages

## ⚙️ Installation & Setup

1. Clone the repository:

```id="clone01"
git clone https://github.com/AbhishekJoshi1209/e-plantShopping.git
```

2. Navigate to the project folder:

```id="cd01"
cd e-plantShopping
```

3. Install dependencies:

```id="install01"
npm install
```

4. Run the development server:

```id="run01"
npm run dev
```

5. Open in browser:

```id="url01"
http://localhost:5173
```
